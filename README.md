# Addition of Two Integers in C

## Description
This C program accepts two integers from the user, adds them, and displays the result.

## Algorithm
1. Start.
2. Declare three integer variables: `iValue1`, `iValue2`, and `iResult`.
3. Ask the user to enter the first number.
4. Read the first number using `scanf()`.
5. Ask the user to enter the second number.
6. Read the second number using `scanf()`.
7. Add the two numbers and store the sum in `iResult`.
8. Display the result using `printf()`.
9. Stop.

## Source File
- `program.c` — contains the C source code.

## Requirements
- A C compiler, such as GCC.
- A terminal or command prompt.

## How to Compile and Run

Compile the program:

```bash
gcc program.c -o program
```

Run on Windows:

```bash
program.exe
```

Run on Linux/macOS:

```bash
./program
```
